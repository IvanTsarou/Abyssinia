# Abyssinia

Интерактивная карта путешествия по Эфиопии: 20 достопримечательностей, фильтры по регионам, страницы локаций, план поездки и маршрут на карте.

- **Стек:** HTML, CSS (Tailwind), JS, Leaflet
- **Данные:** координаты проверены по ЮНЕСКО, GeoHack, Wikipedia
- **Фото:** хранятся в `photos/` (1–8 — Wikimedia Commons, 9–20 — Unsplash и Commons). Загрузка: `./download_photos.sh`. Атрибуция: см. лицензии на страницах файлов в [Commons](https://commons.wikimedia.org/) и [Unsplash](https://unsplash.com/license).

## Запуск

Открыть `index.html` в браузере или поднять локальный сервер (например `npx serve .`).

## Ветка

Проект в ветке `Abyssinia`.
